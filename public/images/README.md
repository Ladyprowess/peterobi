# Pictures

Drop the files here with these exact names. Anything missing falls back to a
green panel automatically, so the site never shows a broken image.

| File | Where it appears | Suggested crop |
|---|---|---|
| `peter-obi.jpg` | Home hero profile card, About page | Square, 1200 x 1200 |
| `health.jpg` | Health card and page header | Landscape, 1600 x 1000 |
| `education.jpg` | Education card and page header | Landscape, 1600 x 1000 |
| `economy.jpg` | Economy card and page header | Landscape, 1600 x 1000 |
| `security.jpg` | Security card and page header | Landscape, 1600 x 1000 |
| `infrastructure.jpg` | Infrastructure card and page header | Landscape, 1600 x 1000 |
| `governance.jpg` | Governance card and page header | Landscape, 1600 x 1000 |
| `investment.jpg` | Investment card and page header | Landscape, 1600 x 1000 |
| `welfare.jpg` | Welfare card and page header | Landscape, 1600 x 1000 |

Keep each file under about 300 KB. Most of the traffic will arrive on phones
over mobile data, and a heavy page is a page people close.

To use `.png` or `.webp` instead, change the paths in `src/lib/content.ts`.
